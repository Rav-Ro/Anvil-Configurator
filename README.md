Anvil Configurator
A Forge 1.20.1 mod that removes Minecraft's vanilla anvil level restriction and allows players to configure the maximum XP cost.

Features
Removes the "Too Expensive!" restriction
Configurable maximum anvil XP cost
Forge 1.20.1
Lightweight and modpack-friendly
Customizable through a config file
Configuration
Edit:

config/anvilconfigurator-common.toml

Example:

maxAnvilCost = 75

Possible values include:

25
50
75
100
250

Any positive integer
Installation:
Install Minecraft Forge 1.20.1
Place the mod jar in the mods folder
Launch the game
