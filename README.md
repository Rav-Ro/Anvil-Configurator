Anvil Configurator
A Forge 1.20.1 mod that removes Minecraft's vanilla anvil level restriction and allows players to configure the maximum XP cost.

https://www.curseforge.com/minecraft/mc-mods/anvil-configurator

Features
Removes the "Too Expensive!" restriction
Configurable maximum anvil XP cost
Forge 1.20.1 support
Lightweight implementation
Modpack-friendly
Configuration
Edit:

config/anvilconfigurator-common.toml

Example:

maxAnvilCost = 75
